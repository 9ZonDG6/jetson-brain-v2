# jetson-brain-v2

Управление 4WD-роботом на Jetson Nano: штатный RC-пульт, веб-пульт, пилот по
командам `robot-vision`, прямой поток с камеры и запись видео. Управление
моторами и защита работают через одну службу; лидар и парктроники ей не
требуются.

## Структура

- `src/jetson_brain_v2/` — Python-приложение, безопасность, GPIO/PWM, ИИ-пилот.
- `src/jetson_brain_v2/web/` — админка.
- `config/` — примеры калибровки ИИ и камеры; рабочие JSON хранятся на роботе.
- `scripts/` — деплой, запуск и остановка.
- `docs/robot-control.md` — подключение, API, ограничения и порядок проверки.
- `tests/` — проверки преобразования ИИ-команд.

## Локальная проверка

```bash
uv sync
uv run python -m unittest discover -s tests -v
uv run jetson-brain-v2 --dry-run --no-cpu-tuning --host 127.0.0.1
```

В dry-run выходы PWM не затрагиваются. Для Jetson, настройки ИИ и камеры см.
[инструкцию по управлению](docs/robot-control.md).

## Jetson

`./scripts/deploy.sh` собирает ARM64-зависимости на рабочей машине, копирует
проект и обновляет `docker compose` на Jetson. Compose запускает контроллер
на порту 8080 и NATS на `127.0.0.1:4222`. Конфигурации, записи и данные NATS
сохраняются между обновлениями. Контроллер стартует в `DISARMED`.
